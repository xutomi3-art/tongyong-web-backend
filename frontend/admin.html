🔐 SSL 证书管理

请使用 Let's Encrypt 或其他SSL证书提供商为您的域名申请免费SSL证书。

📚 推荐工具：

  • Certbot: Let's Encrypt 官方工具，自动化申请和更新
  • acme.sh: 轻量级Shell脚本，支持多种DNS提供商
  • 云服务商: 阿里云、腾讯云等提供免费SSL证书申请服务

👨‍💻 安装示例（Certbot）：

# 安装Certbot
sudo apt install certbot python3-certbot-nginx

# 申请证书（替换为您的域名）
sudo certbot --nginx -d your-domain.com

# 设置自动更新
sudo certbot renew --dry-run
